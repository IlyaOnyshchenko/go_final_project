Проект создан в учебных целях. В нём реализован планировщик задач со следующими функциями:
- Добавление задачи с названием и комментарием
- Удаление задачи
- Отметка задачи выполненной
Добавлять задачу можно с условием периодичности, а также без неё. Можно повторять задачу ежедневно (либо через какой-то интервал дней), еженедельно с указанием дня недели в формате 1-7,
ежемесячно (в формате m номер месяца день месяца), ежегодно. Все функции реализованы.
В проекте реализована поддержка переменных окружения:
- TODO_PORT = 7540
- TODO_PASSWORD = 12345
Файл БД создаётся автоматически, если он не создан, а также в него добавляются нужные колонки для таблицы.
Реализованы запросы поиска задачи. 

Для запуска программы необходимо в корне проекта прописать команду go run main.go. Для запуска тестов - go test ./tests. Для демонстрации пройденных тестов создан workflow, залит образ в DockerHub.
Для запуска Docker-образа прописать команду docker run -d -p 8080:8080 ilyaonyshschenko1994/todo-app-repo:latest

В директории `tests` находятся тесты для проверки API, которое должно быть реализовано в веб-сервере.

Директория `web` содержит файлы фронтенда.
